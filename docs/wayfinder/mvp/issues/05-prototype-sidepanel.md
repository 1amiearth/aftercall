## Question

Side Panel ควรหน้าตาและเปลี่ยนสถานะอย่างไร ให้ผู้บันทึกรู้ตลอดว่ากำลังเกิดอะไร และแก้ปัญหาได้เองโดยไม่ต้องเดา

สถานะที่ต้องมี

- ไม่ใช่แท็บ Meet
- พร้อมบันทึก (มีหรือไม่มี API key)
- กำลังบันทึก / พัก พร้อมเวลา
- ยังไม่เปิด CC (คำเตือนค้าง)
- กำลังสรุป / สรุปเสร็จ / สรุปไม่สำเร็จ + ปุ่มสรุปใหม่
- ยังไม่ได้ตั้งชื่อผู้บันทึก หรือยังไม่อนุญาตไมค์
- หน้าตั้งค่า: API key, โมเดล, ชื่อผู้บันทึก, สวิตช์ไมค์, สวิตช์การแจ้งในแชทพร้อมคำเตือนตอนปิด

ผลลัพธ์: HTML แบบคลิกได้ ไม่ต่อกับ API จริง ลองทั้งไทยและอังกฤษ
